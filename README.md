## 📊 Understanding Keystroke Par

Keystroke par is the target number of key presses for a drill. A lower count means you completed the task more efficiently. Par is not a strict pass-or-fail score. It is a guide that shows you what efficient movement looks like.

When you beat par, you are building faster habits. When you miss par, the app helps you see where extra keystrokes crept in. Over time, those small improvements add up. You learn to move with purpose instead of reaching for the mouse or repeating the same key more than needed.
